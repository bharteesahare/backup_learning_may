## 🟢 **What is Node.js?**

### ✅ Definition:

Node.js is an **open-source**, **cross-platform JavaScript runtime** built on **Chrome's V8 JavaScript engine**. It allows you to run JavaScript **outside the browser**, mainly on servers.

> 🔥 Node.js is great for building **scalable network applications**, APIs, CLI tools, and real-time apps like chat systems.

### ✅ Key Features:

* Non-blocking, **asynchronous I/O**
* **Single-threaded** (with internal thread pool)
* Uses **event-driven architecture**
* Comes with **built-in modules** like `fs`, `http`, `path`, etc.

### ✅ Real-world Example:

Instead of using PHP or Java for backend, you can now use **JavaScript everywhere** – front-end + back-end – using Node.js.

## 🔁 **Node.js Runtime vs Browser JavaScript**

| Feature              | Node.js                          | Browser                      |
| -------------------- | -------------------------------- | ---------------------------- |
| Environment          | Server-side                      | Client-side (in the browser) |
| Global Object        | `global`                         | `window`                     |
| File System Access   | ✅ Yes (`fs` module)              | ❌ No                         |
| DOM Access           | ❌ Not available                  | ✅ Yes                        |
| HTTP Server Creation | ✅ Built-in (`http` module)       | ❌ Use external servers       |
| Module System        | CommonJS (require/export) or ESM | ES Modules (import/export)   |

### Example:

**In Browser:**

```js
console.log(window.location.href);
```

**In Node.js:**

```js
console.log(__dirname); // prints current directory
```

## 💻 **REPL (Read-Eval-Print Loop)**

> A command-line **interactive environment** where you can type JavaScript and see results instantly.

### ✅ To start REPL:

```bash
node
```

### ✅ Example:

```bash
> 2 + 3
5
> const a = 10;
undefined
> a * 2
20
```

### ✅ Useful REPL Commands:

* `.exit` — Exit REPL
* `.help` — List all REPL commands
* `.editor` — Multi-line editing mode

## 🌍 **Global Objects in Node.js**

These are available **everywhere** in Node.js without importing anything.

| Object       | Description                                         |
| ------------ | --------------------------------------------------- |
| `global`     | Like `window` in browsers                           |
| `__dirname`  | Absolute path of current directory                  |
| `__filename` | Absolute path of current file                       |
| `module`     | Info about current module                           |
| `require`    | To import other modules                             |
| `process`    | Info about running process (env, memory, PID, etc.) |
| `Buffer`     | To handle binary data                               |

### ✅ Example:

```js
console.log(__filename); // /Users/me/app/index.js
console.log(process.pid); // 25145
```

## 📦 **npm vs npx**

### 🔸 npm (Node Package Manager)

Used to:

* Install packages (libraries)
* Initialize and manage `package.json`
* Download dependencies

#### Commands:

```bash
npm init         # Create package.json
npm install axios    # Install axios locally
npm install -g nodemon  # Install globally
```

---

### 🔸 npx (Node Package Runner)

Used to:

* **Run packages** without installing them globally
* Execute binaries directly from `node_modules/.bin`

#### Examples:

```bash
npx create-react-app my-app
npx nodemon server.js
```

> ⚠️ Think of `npx` as a "shortcut runner" for one-time commands.

## 🔧 **Built-in Modules in Node.js**

These modules are included with Node.js, so **no need to install via npm**.

---

### 📁 1. `fs` (File System)

Used to read, write, and manage files.

```js
const fs = require('fs');

fs.readFile('file.txt', 'utf8', (err, data) => {
  if (err) throw err;
  console.log(data);
});
```

---

### 📂 2. `path`

Handles file paths across platforms.

```js
const path = require('path');

console.log(path.join(__dirname, 'file.txt')); 
```

---

### 🌐 3. `http`

Create HTTP server.

```js
const http = require('http');

http.createServer((req, res) => {
  res.end('Hello World');
}).listen(3000);
```

---

### 💻 4. `os`

Provides info about the operating system.

```js
const os = require('os');

console.log(os.platform()); // win32, linux, darwin
console.log(os.totalmem());
```

---

### 📢 5. `events`

Create and handle custom events.

```js
const EventEmitter = require('events');
const emitter = new EventEmitter();

emitter.on('greet', () => console.log('Hello!'));
emitter.emit('greet');  // triggers the event
```
