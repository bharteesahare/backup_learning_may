## 🧩 Prerequisites → **JavaScript (ES6+)**

### ✅ **Core Concepts You Must Know**

---

### 1. `let` and `const`

* `let`: Block-scoped variable. Can be updated, **not re-declared** in the same scope.
* `const`: Also block-scoped. **Cannot be updated or re-declared**.

```js
let x = 10;
x = 20; // ✅

const y = 30;
y = 40; // ❌ Error: Assignment to constant variable
```

---

### 2. **Arrow Functions**

* Shorter syntax for functions.
* **Does not bind its own `this`** (inherits from parent).

```js
const add = (a, b) => a + b;

const user = {
  name: "Bhartee",
  greet: () => {
    console.log(this.name); // `this` is undefined here
  }
};
```

---

### 3. **Promises**

* A way to handle asynchronous operations.
* States: `pending`, `fulfilled`, `rejected`

```js
let promise = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Success!"), 1000);
});

promise.then(result => console.log(result)); // Output after 1s: "Success!"
```

---

### 4. **async/await**

* Cleaner way to write asynchronous code using Promises.

```js
async function fetchData() {
  try {
    let data = await fetch("https://api.example.com");
    let json = await data.json();
    console.log(json);
  } catch (err) {
    console.error("Error:", err);
  }
}
```

---

### 5. **Destructuring**

* Extract values from arrays or properties from objects.

```js
// Object destructuring
const user = { name: "Bhartee", age: 25 };
const { name, age } = user;

// Array destructuring
const nums = [1, 2, 3];
const [a, b] = nums;
```

---

### ✅ Why This is Important for Node.js

Understanding ES6+ syntax is crucial because:

* Most Node.js libraries and frameworks use it.
* Code readability and maintainability improves.
* Helps when working with modules, callbacks, and async logic.
