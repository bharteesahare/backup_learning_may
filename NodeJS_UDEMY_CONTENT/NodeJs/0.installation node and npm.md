Yes! If `nvm` continues failing due to persistent permission errors, you can **install Node.js manually** without `nvm`. This method is **clean, fast, and works 100%** when `nvm` is problematic.

---

## ✅ Manual Node.js Installation on Linux

We'll:

1. Download the latest Node.js LTS binary
2. Extract and place it in `/opt/nodejs`
3. Add it to your system's `PATH`

---

### 🧰 Step-by-Step Instructions

### 🔽 1. **Download Node.js LTS binary**

```bash
cd ~
curl -O https://nodejs.org/dist/v22.16.0/node-v22.16.0-linux-x64.tar.xz
```

---

### 📦 2. **Extract the archive**

```bash
tar -xf node-v22.16.0-linux-x64.tar.xz
```

---

### 🚚 3. **Move it to a system directory**

```bash
sudo mv node-v22.16.0-linux-x64 /opt/nodejs
```

---

### 🔗 4. **Add Node.js to your PATH**

Add these lines to your shell config file (`~/.bashrc` or `~/.zshrc`):

```bash
export PATH=/opt/nodejs/bin:$PATH
```

Then apply it:

```bash
source ~/.bashrc   # or source ~/.zshrc
```

---

### ✅ 5. **Verify installation**

```bash
node -v
npm -v
```

You should now see:

```
v22.16.0
10.x.x (npm version)
```

---

## 🧽 (Optional) Clean up

```bash
rm ~/node-v22.16.0-linux-x64.tar.xz
```

Run Hello world program in node js:
Great! Once Node.js is installed, you can easily run a **Hello World** program using JavaScript. Here's how to do it step by step:

---

## ✅ Step-by-Step: Run a Node.js "Hello World" Program

### 📝 1. **Create a file**

Create a new file called `hello.js` using any text editor or terminal:

```bash
nano hello.js
```

Paste this content:

```js
console.log("Hello, Node.js!");
```

Press `Ctrl + O` to save, then `Enter`, then `Ctrl + X` to exit (if using `nano`).

---

### ▶️ 2. **Run it using Node**

```bash
node hello.js
```

### ✅ Output:

```
Hello, Node.js!
```

---

## 💡 Alternate: Run Node.js code without a file

You can also directly run one-liners in the terminal:

```bash
node -e "console.log('Hello from Node!')"
```

Or start the Node REPL (interactive shell):

```bash
node
```

Then type:

```js
console.log("Hi from REPL!");
```

Press `Enter` and you’ll see:

```
Hi from REPL!
```
