## 🧠 **JavaScript ES6+ Complete Beginner Notes**

---

### ✅ 1. `let`, `const`, and `var`

| Keyword | Scope    | Reassignable | Hoisted | Use Case         |
| ------- | -------- | ------------ | ------- | ---------------- |
| `let`   | Block    | ✅ Yes        | ❌ No    | Reassignable var |
| `const` | Block    | ❌ No         | ❌ No    | Constants        |
| `var`   | Function | ✅ Yes        | ✅ Yes   | Avoid in ES6+    |

```js
let count = 1;
const name = "Node";
var global = true;
```

---

### ✅ 2. Arrow Functions

* Short syntax
* Inherit `this` from surrounding scope (lexical scope)

```js
const sum = (a, b) => a + b;

const greet = name => console.log(`Hello, ${name}`);
```

> Avoid arrow functions for object methods when dynamic `this` is needed.

---

### ✅ 3. Template Literals

Use backticks `` ` ``, and `${}` for expression interpolation.

```js
const user = "Bhartee";
console.log(`Welcome, ${user}!`);
```

---

### ✅ 4. Destructuring

#### 📍 Arrays

```js
const arr = [1, 2, 3];
const [a, b, c] = arr; // a=1, b=2, c=3
```

#### 📍 Objects

```js
const user = { name: "Neo", age: 30 };
const { name, age } = user;
```

---

### ✅ 5. Default Parameters

```js
function greet(name = "Guest") {
  console.log(`Hello, ${name}`);
}
```

---

### ✅ 6. Spread and Rest (`...`)

#### 📍 Spread

```js
const nums = [1, 2, 3];
const newNums = [...nums, 4, 5]; // [1, 2, 3, 4, 5]
```

#### 📍 Rest

```js
function sum(...args) {
  return args.reduce((a, b) => a + b);
}
```

---

### ✅ 7. Enhanced Object Literals

```js
const age = 30;
const user = {
  name: "Alice",
  age,              // same as age: age
  greet() {         // method shorthand
    console.log("Hi!");
  }
};
```

---

### ✅ 8. Promises

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Done!"), 1000);
});

promise.then(result => console.log(result)).catch(err => console.error(err));
```

---

### ✅ 9. `async` / `await`

```js
async function fetchData() {
  try {
    const res = await fetch("https://api.example.com");
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}
```

---

### ✅ 10. Classes

```js
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log(`Hello, I'm ${this.name}`);
  }
}
```

---

### ✅ 11. Modules (`import` / `export`)

```js
// utils.js
export const add = (a, b) => a + b;

// main.js
import { add } from './utils.js';
```

---

### ✅ 12. `Map` and `Set`

```js
const map = new Map();
map.set("name", "John");
console.log(map.get("name")); // "John"

const set = new Set([1, 2, 2, 3]);
console.log(set); // Set { 1, 2, 3 }
```

---

### ✅ 13. Optional Chaining (`?.`) & Nullish Coalescing (`??`)

```js
const user = { profile: { name: "Max" } };
console.log(user?.profile?.name); // "Max"

const value = null ?? "default";
console.log(value); // "default"
```
